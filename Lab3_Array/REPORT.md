# ЗВІТ ПРО ВИКОНАННЯ ЛАБОРАТОРНОЇ РОБОТИ №3
**Тема:** Створення структури «список» за допомогою масиву  

---

## 1. Мета роботи
Засвоїти практичні навички представлення лінійних списків у пам'яті комп'ютера за допомогою статичних масивів у C++; реалізувати базові операції над списком (обнулення, вставка, видалення, перевірка стану) та навчитися обробляти елементи відповідно до заданих умов.

---

## 2. Постановка задачі
1. Задати розмір масиву `dovz` та описати тип `List` із полями `elems` (цілочисельний масив) та `last` (позиція останнього елемента списку).
2. Реалізувати функцію `make_null(L)`.
3. Реалізувати операцію `insert(L, x, i)` перед $i$-м елементом зі зсувом елементів праворуч.
4. Вставити кілька значень у список.
5. Реалізувати видалення $i$-го елемента `remove_at(L, i)` зі зсувом елементів ліворуч.
6. Реалізувати предикат `is_full(L)`.
7. Реалізувати предикат `is_empty(L)`.
8. Реалізувати предикат `is_valid(L, i)`.
9. Заповнити список значеннями, перед кожним додатним елементом вставити нульовий елемент. Вивести результуючий список та його довжину.

---

## 3. Лістинг реалізації (основні фрагменти)

```cpp
// 3
bool insert(List &L, int x, int i) {
    if (is_full(L) || i < 1 || i > L.last + 1) return false;
    for (int p = L.last; p >= i; --p) {
        L.elems[p] = L.elems[p - 1];
    }
    L.elems[i - 1] = x;
    L.last++;
    return true;
}

// 5
bool remove_at(List &L, int i) {
    if (is_empty(L) || !is_valid(L, i)) return false;
    for (int p = i; p < L.last; ++p) {
        L.elems[p - 1] = L.elems[p];
    }
    L.last--;
    return true;
}

// 9
void insert_zero_before_positives(List &L) {
    int i = 1;
    while (i <= L.last) {
        if (L.elems[i - 1] > 0) {
            if (insert(L, 0, i)) {
                i += 2;
            } else {
                break;
            }
        } else {
            i++;
        }
    }
}
```

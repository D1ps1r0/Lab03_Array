# Лабораторна робота №3: Створення структури «список» за допомогою масиву

Реалізація абстрактного типу даних «Список» на основі одновимірного статичного масиву мовою C++ (пункти 1–9 методичних вказівок).

Для забезпечення коректного відображення української мови в консолі без сторонніх платформозалежних бібліотек використовується стандартний засіб: `std::setlocale(LC_ALL, "uk_UA.UTF-8");` (заголовний файл `<clocale>`).

---

## 📌 Пункти лабораторної роботи

- **1.** Опис типу `List` (масив `elems` розміру `dovz` та позиція останнього елемента `last`).
- **2.** Функція `make_null(L)` для скидання списку.
- **3.** Функція `insert(L, x, i)` для вставки елемента $x$ перед $i$-м елементом зі зсувом вправо.
- **4.** Вставка початкових елементів списку.
- **5.** Процедура `remove_at(L, i)` для видалення $i$-го елемента зі зсувом вліво.
- **6.** Логічна функція `is_full(L)` — перевірка заповненості.
- **7.** Логічна функція `is_empty(L)` — перевірка на порожнечу.
- **8.** Логічна функція `is_valid(L, i)` — перевірка валідності позиції.
- **9.** Вставка нуля (`0`) перед кожним додатним значенням, виведення списку та його довжини.

---

## 🛠 Збірка та запуск

```bash
g++ -std=c++17 -Wall -Wextra main.cpp -o lab3
./lab3
```
